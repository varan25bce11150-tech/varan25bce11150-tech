## Featured projects

### [ScamShield AI](https://github.com/varan25bce11150-tech/ScamShield__AI)

Decision-support tool that checks a UPI payment for scam and social-engineering signals before it's made. Produces an explainable 0–100 risk score with an allow / warn / block decision, scans UPI QR codes and keeps an audit trail.

`FastAPI` `React` `TypeScript` `spaCy` `SQLAlchemy` `SQLite`

### [Sentinel Monitoring](https://github.com/varan25bce11150-tech/sentinel-monitoring)

Uptime and health monitoring for web services, with scheduled background checks, latency tracking, JWT authentication and a telemetry dashboard. Runs locally as a multi-container Docker Compose setup.

`Next.js` `TypeScript` `FastAPI` `PostgreSQL` `Redis` `Docker`

### [InkSpace](https://github.com/varan25bce11150-tech/InkSpace)

Django blogging platform with user accounts, a draft-and-publish workflow, categories, search, pagination and moderated comments.

`Django` `Python` `SQLite` `HTML/CSS` `JavaScript`

### [Nimbus](https://github.com/varan25bce11150-tech/nimbus-weather)

Flask weather dashboard built on the Open-Meteo API, with city search, current-location weather, hourly and 7-day forecasts and a responsive layout. Built during my Pinnacle Labs internship.

`Flask` `Python` `JavaScript` `Open-Meteo API`

### [Nifty100 Data Foundation](https://github.com/varan25bce11150-tech/nifty100-data-foundation)

Financial analytics pipeline for Nifty100 companies: data ingestion into SQLite, financial ratio calculations, stock screening, peer comparison and a Streamlit dashboard with generated company reports.

`Python` `Pandas` `SQLite` `Streamlit` `Plotly`

### [SMS Spam Detection](https://github.com/varan25bce11150-tech/spam_detection)

Classifies SMS messages as spam or legitimate using an NLP preprocessing pipeline with TF-IDF features and a Multinomial Naive Bayes model.

`Python` `scikit-learn` `NLTK` `Pandas`
